# About these docs

Start here. This folder is the working documentation for grate: reviews, plans and task write-ups, numbered in creation order.

The folder follows the `wj` docs convention; run `wj conventions` for the rules and `wj lint` to check them. Project specifics:

- Numbers are two digits wide.
- Reviews are snapshots — they state their date and the commit they assessed; they are not updated to track the code. Tasks and the plan are living documents.
- `31` was allocated twice; the later doc, Playtime corrections, was renumbered to `35`.
